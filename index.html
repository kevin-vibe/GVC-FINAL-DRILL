My Project

Rotating Windmill Blades

A math-based animation created using p5.js. This project demonstrates how mathematics, geometry, angles, and trigonometry can be used to create movement in a digital animation.

Animation Controls

  • P - Pause or resume the animation.
  • I - Increase the rotation speed.
  • D - Decrease the rotation speed.
  • R - Reset the animation.

Mathematical Concepts

The windmill uses radians and angular rotation. Each blade is positioned 90 degrees apart using the HALF_PI constant. The rotation angle increases every frame to create continuous movement.
