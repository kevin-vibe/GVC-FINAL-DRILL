Rotating Windmill Blades

Math-Based Animation Using p5.js

Windmill Animation

This animation demonstrates the rotation of a windmill using mathematical concepts such as angles, radians, and trigonometry.

Animation Controls

  • P: Pause or resume the animation.
  • I: Increase the rotation speed.
  • D: Decrease the rotation speed.
  • R: Reset the animation.

Mathematical Explanation

1. Angular Rotation

The windmill rotates by continuously increasing its rotation angle. The angle is updated every frame using the formula:

New Angle = Previous Angle + Rotation Speed

2. Radians and Angles

The animation uses radians to calculate the position of each blade. One complete rotation is equal to 2π radians or 360 degrees.

3. Four-Blade Arrangement

The windmill has four blades positioned equally around the center. Each blade is separated by 90 degrees, which is represented by HALF_PI in p5.js.

4. Rotation Speed

Changing the rotation speed changes how quickly the blades rotate. A higher value makes the windmill spin faster, while a lower value makes it spin slower.
